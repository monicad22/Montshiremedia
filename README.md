# Montshire Media

A private, 24-page editorial website preview. Static semantic HTML is generated by `build.py`; CSS and JavaScript live in `dist/`. No framework, external fonts, tracking scripts or stock imagery are required.

## Edit and preview

Edit the service entries in `content.json`, then run `python3 build.py`. Other editorial sections and page templates are in `build.py`. This first version supports service edits without code changes; adding case studies and articles currently requires editing their data arrays in the generator. Run `python3 -m http.server 4173 --directory dist` to preview.

The Sites identity is preserved in `.openai/hosting.json`. Publish through the Sites workflow. Do not create a replacement Site to update this one.

## Current limits

This is a deployable static preview, not a fully integrated production lead system. The form validates locally and creates a downloadable enquiry; it does not claim to send emails or collect leads. Newsletter and calendar integration are explicitly pending. No server-side validation, anti-spam service, notification routing, CRM connection, or live analytics is configured. Implement those in a server runtime before switching the form to live submission. Do not put service credentials in browser code.

Legal pages are drafts requiring business-specific and legal review. Performance and WCAG conformance are targets, not certified outcomes. Metric counters, client logo marquee and testimonial slider are intentionally withheld until verified content exists. The proof area uses explicit case-study placeholders. LocalBusiness and Article schemas should be added only once verified business and publication details are available. Organization, Service, FAQPage and BreadcrumbList data are included where applicable.

## Launch checklist

- Confirm legal business name, founder name (brief says Monica Dhaya), bio, contact details and brand approval.
- Replace or remove all placeholder case studies, results, credentials, quote and founder photo. Obtain permissions for client names/logos and quotes.
- Configure a server endpoint with strict field validation, length limits, origin checks, rate limiting/bot protection, secure email delivery and failure handling. Test delivery and avoid logging sensitive message contents.
- Configure booking and newsletter provider, verified sender, consent records and unsubscribe flow. Confirm CASL requirements and privacy practices with qualified reviewers.
- Finalize Privacy, Terms and Cookie policies against actual hosting, data flows and retention. Audit provider cookies and security headers.
- Configure domain/DNS and HTTPS. Update `origin` in build.py, regenerate canonical tags and sitemap; add permanent redirects if URLs change.
- Remove noindex and robots restrictions only after all draft/placeholder pages are approved, replaced or excluded.
- Add verified address and contact fields to LocalBusiness schema; add approved byline/date to Article schema. Validate structured data and social cards.
- Configure GA4/GTM through a real consent integration with default-denied settings. The current dataLayer hooks are placeholders, not a complete Google Consent Mode setup. Avoid PII in events. Verify booking, CTA and actual submission conversions.
- Verify Search Console, submit sitemap and inspect priority URLs. en-CA/en-US currently point to the same shared English content; add separate URLs only if localized pages are created.
- Test desktop/mobile browsers, 320–2560px, keyboard and screen reader paths, dark mode, reduced motion, error states and a real mobile device. Audit contrast and WCAG 2.2 AA.
- Run Lighthouse on the production URL and field measurement after traffic arrives. Target 95+ scores and LCP <2.5s, INP <200ms, CLS <0.1; no score has been claimed.
- Configure CSP, HSTS, X-Content-Type-Options, Referrer-Policy and Permissions-Policy at the production hosting layer; verify response headers. Static HTML alone cannot guarantee these headers.
